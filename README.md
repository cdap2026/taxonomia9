# Laboratorio Virtual: Sistemática y Taxonomía Avanzada

Plataforma interactiva de aprendizaje diseñada para estudiantes de **Grado 9° de Ciencias Naturales** en **The Lighthouse School**. Esta aplicación permite a los estudiantes aplicar conceptos avanzados de biología evolutiva, taxonomía y sistemática para identificar organismos de la biodiversidad colombiana.

## 🧬 Enfoque Pedagógico (Nivel 9° Grado)
A diferencia de claves basadas puramente en formas visuales simples, esta versión exige al estudiante manejar terminología científica real:
- Diferenciación entre nutrición autótrofa y heterótrofa.
- Tipos de tejidos (ej. sistemas vasculares: xilema/floema).
- Estructuras de soporte (endoesqueleto vs exoesqueleto, notocorda).
- Regulación térmica (ectotermia vs endotermia).
- Reproducción y embriología (holometabolía, semilla vs espora, angiospermas vs pteridofitas).

## 🔬 Especies Analizadas
1. **Oso de Anteojos** (*Tremarctos ornatus*) - Chordata, Mammalia
2. **Rana Dorada Venenosa** (*Phyllobates terribilis*) - Chordata, Amphibia
3. **Escarabajo Hércules** (*Dynastes hercules*) - Arthropoda, Insecta
4. **Flor de Mayo** (*Cattleya trianae*) - Angiospermae, Monocotiledónea
5. **Helecho Arbóreo Bobo** (*Cyathea caracasana*) - Pteridophyta

## 🛠 Instalación y Despliegue (GitHub Pages)
1. Extrae los archivos `index.html` y `README.md` de este ZIP.
2. Súbelos a un nuevo repositorio público en tu cuenta de GitHub.
3. Dirígete a **Settings > Pages**.
4. En **Source**, selecciona `Deploy from a branch` y elige tu rama principal (`main`).
5. Comparte la URL generada con tus estudiantes de 9° grado para el trabajo en el aula o como tarea en casa. Es 100% responsivo para móviles.
